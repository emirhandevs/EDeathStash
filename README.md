# 📦 eDeathStash | Smart Loot Stash Chests for PvP & Survival Servers

🔗 **Modrinth:** https://modrinth.com/emirhandevs/eDeathStash

Tired of cluttered ground drops after intense PvP fights or mob grinding? **eDeathStash** is a lightweight, configurable plugin for **Paper & Spigot** (`1.20.1` – `1.21.11`) that neatly packs player and mob loot into a single unplaceable stash chest item for fast previewing and instant claiming[cite: 9].

---

### ✨ Key Features

* 📦 **Single-Chest Loot Packing:** When a player with `/stash` enabled kills a mob or another player, all dropped items are packed into a single stash chest instead of scattering across the ground[cite: 9].
* 👁️ **Left-Click Loot Preview:** Left-clicking while holding the stash chest opens a read-only preview GUI so you can inspect the contents safely without taking items out[cite: 9].
* ⚡ **Right-Click Instant Claim:** Right-clicking with the stash chest transfers all stored items directly into your inventory and removes the chest[cite: 9].
* 🎒 **Smart Overflow Handling:** If your inventory runs out of space while claiming, any remaining items drop safely at your feet so nothing is lost[cite: 9].
* 🚫 **Unplaceable Protection:** Stash chests cannot be placed down as blocks under any circumstances, preventing duplication or accidental placement[cite: 9].
* 🔧 **Configurable & Permission-Based:** Control access via player and admin permissions and customize behavior through `config.yml` for Paper and Spigot `1.20.1` through `1.21.11`[cite: 9].

---

### 💻 Commands & Permissions

| Command | Description | Access |
| :--- | :--- | :--- |
| `/stash` | Toggles automatic loot stash chest drops on or off[cite: 9]. | Player Permission |
| `/edeathstash reload` | Reloads the plugin configuration files without restarting the server[cite: 9]. | Admin Permission |
| `/edeathstash status` | Displays the current status and active state of the plugin. | Admin Permission |

---

### ⚙️ Installation & Configuration

1. Download the `.jar` file matching your Paper or Spigot version (`1.20.1` – `1.21.11`) and place it in your server's `/plugins` folder[cite: 9].
2. Restart or start your server to generate the default configuration files.
3. Grant the player permission to users who should have access to `/stash` and the admin permission to staff[cite: 9].
4. Adjust settings in `plugins/eDeathStash/config.yml`, then run `/edeathstash reload` and verify with `/edeathstash status`.
